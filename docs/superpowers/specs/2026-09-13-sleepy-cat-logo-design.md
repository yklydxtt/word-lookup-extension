# 蜷睡猫标识替换设计

日期：2026-09-13

选择依据：用户最后明确选择第三款「蜷睡猫」，覆盖此前第一款选择。图形沿用已经展示的闭眼、蜷卧、卷尾小猫，不重新设计造型。

## 范围

- 替换工具栏菜单原来的“词”字标识。
- 为扩展管理页及浏览器工具栏声明小猫图标。
- 不改扩展名称、版本、权限、查词卡片、词库、语音和设置逻辑。
- 历史三方案预览与首版验收截图保留，不将历史截图冒充新版实测。

## 视觉

- 保留第三款的圆角线条、双耳、闭眼及卷尾，透明背景、无文字、无额外装饰。
- 浏览器静态图标使用既有绿色 `#287a56`，以 PNG 提供 16、32、48、128 像素版本。
- 工具栏菜单通过同一矢量图形的遮罩继承主题色：浅色 `#287a56`，深色 `#8bd7ae`；保留原有浅绿圆角底和菜单布局。
- 16 像素版本适度加粗线条，避免小尺寸显示时丢失猫耳和卷尾。

## 工程与验证

- 以 `src/assets/cat-logo.svg` 为唯一正式图形源，不从截图裁切。
- 使用固定版本 `@resvg/resvg-js` 作为开发依赖，在构建期生成 PNG；扩展运行时不引入绘图库或网络请求。
- 在 `manifest.icons` 与 `action.default_icon` 声明图标；构建复制 SVG 和生成 PNG，产物校验检查图标完整性与尺寸。
- 增加图标生成、声明与菜单引用测试，执行现有测试、类型检查、构建和词库校验。
- 比较构建前后的内容脚本、后台、菜单脚本与词库索引哈希，确认功能逻辑没有改变。
- 仅检查本扩展，不更改浏览器原生权限或其他扩展；如无法完成实际浏览器重载，明确告知用户手动重新加载。
