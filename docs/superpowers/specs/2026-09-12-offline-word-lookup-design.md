# 离线英文划词查词扩展设计

日期：2026-09-12

状态：首版已实现并由用户确认验收；`ego lite` 真实扩展查词、交互、设置及后台冷启动已验证，卡片内选区误关闭已修复并复测。实际听音和断网查词、发音按用户人工确认记录；完整网络链路等未测项目保留原状态，具体证据见 `docs/qa/ego-lite-acceptance.md`。

## 1. 目标与验收环境

为个人日常阅读提供一个免费、免配置的浏览器扩展：选中英文单词后，在附近显示中文释义、音标和发音按钮。

- 采用本地加载扩展的安装方式，不发布扩展商店。
- 以桌面 Chromium 扩展体系为目标，使用 `Manifest V3 + TypeScript`。
- 保留 Chrome、Edge 兼容目标，但实机验收仅在 `ego lite` 中进行，不要求分别测试 Chrome、Edge。
- 未执行 Chrome、Edge 实机测试时，交付报告必须标注未验证，不将技术兼容目标描述成验收通过。
- 日常查词及发音不依赖网络、API Key、后端或账号。

## 2. 首版范围

### 包含

- 双击或拖动选中英文单词后自动显示卡片。
- 本地中文释义、词性、词库音标和手动发音。
- 原词条优先、基于词库关联的原形回查。
- 全局启停和按完整域名记忆的网站启停。
- 卡片定位、边界避让、内部滚动及明确的异常状态。
- 内置分片词库、后台统一查词和有上限的内存缓存。

### 不包含

- 鼠标悬停取词、短语和整句翻译。
- 根据页面上下文选择词义或生成释义。
- PDF、图片取词、输入框和编辑器内部查词。
- 自动朗读、联网语音或真人音频服务。
- 例句、生词本、查词历史、账号、云同步。
- 移动端、Safari、Firefox 的兼容与验收。
- 自动联网兜底或运行时下载词库。

此前讨论过的联网查词与结果缓存方案，已由“内置词库、完全本地查询”取代。

## 3. 选词与查询语义

### 3.1 有效选区

- 支持普通网页中可选中的文本，不要求取词区域具有特定页面结构。
- 去除首尾空白及包裹单词的标点后，进行不区分大小写的查询。
- 接受由英文字母构成的单词，以及字母之间的连字符或撇号；弯撇号规范化为直撇号。
- 不将词内的连字符或撇号直接删除，避免把不同拼写合并。
- 多个单词、中文、纯数字及不符合上述规则的选区不触发查词。
- 输入框、文本域、可编辑区域及能够识别的编辑器区域不触发查词。
- 卡片内部选中或复制文本不触发新一轮查词。
- 出现新的无效选区时关闭旧卡片，避免旧结果与当前选区不一致。
- 未选中时保留网页原样，不批量添加下划线、高亮、按钮或包裹正文；选中时只使用浏览器原生选区与独立卡片。

### 3.2 查询顺序

1. 查询规范化后的完整词条。
2. 原词条不存在时，通过词库提供的词形关联查询原形。
3. 原词及原形均未命中时，返回“本地词库未收录”。

不使用简单删除 `-s`、`-ed`、`-ing` 等词尾的方式猜测原形。

如果词库给出多个可用原形，不静默猜选其中一个；在同一张卡片中分别标注各原形及对应信息。

### 3.3 信息对应关系

- 原词条命中时，音标、释义和发音对应该词条。
- 回查原形时，保留用户选中的词，并显示如 `went → go` 的关系。
- 回查结果的音标、释义和发音均对应标明的原形，而不是默认对应原始选区。
- 多义词展示词典提供的多个中文释义，不读取上下文来判断最合适的意思。
- 词性有明确标记时按词性组织；无法可靠解析的释义保留原文，不根据猜测补词性。
- 音标按词库数据展示；缺失时提示“暂无音标”，不合成或推测音标。

## 4. 架构与模块边界

首版使用轻量界面实现，不引入重型界面框架。

| 模块 | 职责 | 不负责 |
| --- | --- | --- |
| 页面脚本 | 检查选区、读取启停状态、发送查词消息、管理卡片位置和生命周期 | 加载完整词库、向外发送页面信息 |
| 查词后台 | 校验消息、读取扩展包内分片、查询词条和原形、管理缓存 | 操作网页 DOM、推断上下文词义 |
| 发音模块 | 枚举本地英语语音、选择口音、播放指定词条、报告错误 | 默认语音兜底、联网音频请求 |
| 工具栏菜单 | 展示全局和当前网站开关、提示受限页面 | 管理查词历史或账户 |
| 词库构建模块 | 提取所需数据、生成分片和词形关联、记录来源与版本 | 在用户查词时联网更新 |

页面通过扩展内部消息与后台交互。消息只携带查询词、请求标识等必要信息，不携带正文或上下文。

后台仅依据受控的规范化词定位分片，不允许页面消息指定任意资源路径或外部 URL。

卡片使用 Shadow DOM 等方式隔离自身样式，避免全局 CSS 污染宿主网页；词库内容作为文本渲染，不当作 HTML 执行。

### 4.1 数据流

选中单词 → 检查全局及网站开关 → 校验和规范化选区 → 显示查词中状态 → 后台读取本地分片 → 查询原词或原形 → 更新卡片。

- 同一页面始终只有一张查词卡片。
- 每次有效选词关联独立请求标识；只接收当前有效请求的结果。
- 连续选词、关闭卡片或停用插件后，旧请求的返回结果不得覆盖新结果或重新打开卡片。
- 同一分片的并发加载应复用进行中的读取任务。
- 后台休眠或重启后可以重新读取包内分片，不依赖内存缓存保证正确性。

## 5. 词库与缓存

### 5.1 数据来源

使用 [ECDICT](https://github.com/skywind3000/ECDICT) 作为首版候选数据基础，其项目文档提供中文释义、音标和词形变化字段；音频字段标注为待添加，因此不依赖该字段发音。

实施时应固定使用的数据版本及校验值，保留来源和上游许可文件。仓库声明的许可证不应被表述为对全部历史资料来源完成了独立权利核验。

词库准备属于开发构建阶段，允许下载公开数据；最终扩展包必须包含运行所需的全部词库数据。

### 5.2 构建与加载

- 保留词条、中文释义、词性信息、音标及原形关联。
- 去掉首版不使用的考试标签、词频排名等字段，不为缩小包体而静默限制为少量示例词。
- 按规范化词的确定性分片规则生成静态资源；词形关联也可以直接定位，不依赖全量词库常驻内存。
- 跨分片的原形查询按需读取对应分片。
- 索引声明存在的分片缺失、损坏或格式错误属于读取故障；不能误报为词条未收录。
- 构建产物记录词条数量、分片数量、包体大小和数据版本，实际数值以构建统计为准。

### 5.3 缓存边界

- 分片和查询结果仅在扩展后台缓存，页面不各自加载整份词库。
- 使用有固定容量上限的 LRU 缓存，最近未使用的数据优先淘汰。
- 初始上限为 8 个已加载分片、256 条查询结果；在途读取结束后同样执行容量约束。
- 缓存不持久化为查词历史，不使用 `storage.sync`。
- 持久化的用户数据仅包含全局开关和按域名设置的网站开关。

## 6. 卡片与菜单

### 6.1 卡片内容

从上到下展示：

1. 所选单词；必要时显示原形回查关系。
2. 对应词条的音标和标注实际口音的发音按钮。
3. 按词性组织的中文释义，或保留词库原始释义文本。
4. 当前查询或发音异常的必要提示。

卡片贴近选区放置，避开浏览器可视区域边界，不改变网页布局，也不抢占页面键盘焦点。释义较长时限制卡片高度并允许内部滚动。

### 6.2 生命周期

- 点击卡片外部、按 `Esc`、滚动宿主网页时关闭。
- 鼠标移入卡片、点击发音按钮、复制卡片文本和卡片内部滚动时保持打开。
- 选中另一个有效单词时复用同一卡片并更新内容，不叠加浮窗。
- 用户重新点击发音时不叠加多路朗读。

### 6.3 开关

- 全局开关默认开启，网站默认允许查词。
- 网站开关以完整 `hostname` 保存，例如 `docs.example.com` 与 `www.example.com` 分别控制。
- 全局关闭优先于网站设置；重新开启全局开关不清空网站停用记录。
- 设置变更通知已打开的页面；停用后立即关闭已有卡片，并停止接受当前页的新查词请求。
- 当前页面无法运行扩展时，菜单显示不可用原因，不提供误导性的网站启用操作；全局开关仍可操作。

## 7. 本地发音

- 只有明确点击发音按钮才播放。
- 只选择浏览器能够明确标记为本地的系统语音。
- 优先选择本地 `en-GB` 语音；没有时选择本地 `en-US` 语音。
- 按钮按实际选中的语音标注“英式发音”或“美式发音”，不将美式语音标成英式。
- 未找到上述本地语音，或无法确认语音是否本地时，提示缺少可用本地英语语音；不委托系统默认语音隐式兜底。
- 音标按词库显示，不因为选到了美式语音就推测生成美式音标。
- 浏览器语音列表可能异步就绪，初始化状态不直接判定为永久缺少语音。
- 播放失败时明确提示，释义和音标仍可继续查看。

发音模块与查词模块独立。即使 `ego lite` 没有可用本地英语语音，也应能正常查词并验证缺失语音提示；不能将这种降级状态报告成正常发音已经验收通过。

## 8. 权限与隐私

- 用户接受插件在普通 `http`、`https` 网页上运行所需的权限，以及浏览器可能显示的读取和更改网站数据提示。
- 实际用途限定于监听选词、定位卡片及处理当前网站的启停设置。
- 不申请浏览历史、剪贴板等无关权限；本地设置和发音只采用实现所必需的权限。
- 不记录或上传正文、网址、上下文及查词历史。
- 网站停用功能仅本地保存用户选择停用的域名，不记录访问过的网站列表。
- 不请求词典 API、在线音频或遥测服务；不自动下载语音或词库更新。
- 浏览器内部页面、扩展商店等禁止注入脚本的页面不支持查词。

## 9. 异常处理

| 情况 | 行为 |
| --- | --- |
| 查询处理中 | 显示“正在查词”，不展示上一词的释义作为当前结果 |
| 原词及关联原形均不存在 | 显示所选单词与“本地词库未收录” |
| 所需分片读取或解析失败 | 显示“词库读取失败”，与未收录区分 |
| 扩展后台不可用或通信失败 | 显示查词失败提示，不伪造空词条 |
| 音标缺失 | 显示“暂无音标”，释义正常可用 |
| 本地英语语音缺失 | 明确提示缺少语音，不联网兜底 |
| 语音播放失败 | 提示播放失败，不影响释义查看 |
| 当前网页不支持脚本注入 | 工具栏提示当前页面不可用 |

## 10. 验证与交付标准

### 10.1 自动化验证

围绕实际实现建立测试，至少覆盖：

- 大小写、首尾标点、连字符、撇号及无效选区的规范化规则。
- 原词条优先、原形关联、多原形结果及未收录状态。
- 缺音标、数据格式错误、分片丢失和后台通信失败的区别。
- 确定性分片定位、跨片查询、同片并发读取合并和缓存淘汰。
- 全局开关、完整域名开关、设置持久化及变更生效。
- 本地语音筛选、英式优先、美式兜底和禁止远程语音。
- 连续选词及关闭卡片后，过期异步结果不得再次展示。

执行 TypeScript 检查、相关测试和扩展构建；不得用页面演示替代真实扩展加载验证。

### 10.2 `ego lite` 实机验收

只使用 `ego-browser` 操作 `ego lite` 完成本轮浏览器验收，不额外启动 Chrome、Edge 或其他浏览器代测。

验收项目：

1. 通过实际扩展加载方式安装构建产物，检查扩展启动和工具栏菜单。
2. 在普通网页双击及拖动选词，核对中文释义、音标和原形标注。
3. 验证多词、中文、数字、输入框、编辑器及卡片内部选区不误触发。
4. 验证边缘定位、长释义内部滚动、外部点击、`Esc` 和页面滚动关闭。
5. 快速连续选词，确认只显示最后一次的查询结果。
6. 验证全局和当前网站停用、重新启用及设置持久化。
7. 验证实际本地语音的按钮标注、播放以及缺少语音的降级提示。
8. 在查词前断网，使用本次会话尚未查询过的词验证首次查询；本地语音可用时也验证离线播放。
9. 检查页面脚本、扩展后台和发音链路中插件发起的外部请求，区分宿主网页自身流量。
10. 验证受限页面在工具栏显示不可用，不把该限制报告为普通网页查词故障。

涉及扩展安装、权限确认等浏览器自有提示时，由用户完成必要交互，不绕过权限控制。不因自动化入口受限而静默更换浏览器或修改用户浏览器配置。

API 调用成功不等于已经听到正确发音。无法通过当前工具确认的听音效果单独标注，不以程序返回代替听感验收。

### 10.3 结果记录

- 每个验收项标为“通过”“未通过”或“未测试”，并记录证据或阻塞原因。
- 记录 `ego lite` 实际版本、安装方式、词库版本、包体大小和可用语音情况。
- 尚未验证的浏览器兼容性、未获得确认的播放效果不得写成已通过。
- 交付本地安装说明、功能边界、词库来源及许可说明、运行验证结果。
