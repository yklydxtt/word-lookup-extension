## 实测修复

- 问题：Chromium 对 Shadow DOM 内选区做重映射，`document.getSelection()` 的锚点可变成 `HTML`，`isCollapsed` 为 `true`，即便实际已选中卡片中的 `bank`。
- 影响：在 `mouseup` 之后到达的 `selectionchange` 可能把内部选词误判为正文取消选区，关闭卡片。
- 修复：`src/content/events.ts` 使用可用的 `getComposedRanges({ shadowRoots: [host.shadowRoot] })` 确认内部选区，再决定是否关闭；保留普通正文折叠时关闭的规则。
- 证据：先新增失败测试，再修复；两项新增回归及全部 45 项测试通过。重新构建、仅重新加载本扩展后，在真实内部拖选基础上补发延迟事件，卡片仍可见。
- 自审按需求、事件顺序、可选 API 兼容及测试边界核对；未派发未获授权的子代理。
